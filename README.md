# Glori Pacheco Website

Bilingual artist website built from Glori Pacheco's approved EPK and visual moodboard.

## Local development

```bash
npm install
npm run dev
```

## Production checks

```bash
npm run lint
npm run build
npm run preview
```

Editable copy, streaming links, press links, and contact details live in `src/content.ts`.
The public photography used by the site lives in `public/images`.
